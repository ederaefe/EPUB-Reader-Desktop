Self-Hosted Docker Container (GHCR)

Streams full desktop reader to https://localhost:3001
ghcr.io/ederaefe/semply-ebook-reader:latest 
docker run -d \
  --name semply-ebook-reader \
  --shm-size=1gb \
  -p 3001:3001 \
  -v ./semply-config:/config \
  -v ./books:/books \
  ghcr.io/ederaefe/semply-ebook-reader:latest

Security & Network Architecture

Why and When Semply Communicates with Servers

Semply is engineered with an uncompromising local-first security perimeter. We believe desktop software must be completely transparent about every outbound connection.

Distribution Channel

Attested Release Delivery

Official desktop installers and container images are built in isolated GitHub Actions runners from public source code and published with SLSA Build Provenance attestations and SHA-256 checksums. You maintain 100% control over when and how you upgrade.

  • Target: github.com/ederaefe/EPUB-Reader-Desktop/releases
  • Protocol: HTTPS / TLS 1.3 + Sigstore SLSA Provenance
  • Payload: Zero telemetry, zero user identifiers
Network Channel 02

On-Demand Cloud Typography

Semply packages 12 system/publisher fonts offline out of the box. If you choose one of the 65 curated Google Fonts, Semply downloads the standard .woff2 font package directly to your local user storage. Once downloaded, the font stays completely offline forever.

  • Target: fonts.googleapis.com & fonts.gstatic.com
  • Trigger: Explicit user font selection only
  • Persistence: Local disk cache in userData/fonts/
Zero Ingestion Guarantee

100% Local-First Storage Perimeter

Your books, reading habits, annotations, bookmarks, and search queries never leave your device. Everything is stored in local IndexedDB (Dexie v3) inside your native user profile. No accounts, no analytics SDKs, and no tracking cookies.

  • Database: IndexedDB (Dexie v3)
  • Analytics: Zero third-party trackers or telemetry
  • User Accounts: None required. Full functionality offline.
Binary Provenance

Open-Source Auditing & Hash Verification

Every installer binary (.exe, .dmg, .AppImage) is compiled directly from public GitHub source code through transparent GitHub Actions pipelines. Published releases provide cryptographic SHA-256 hashes so you can independently verify binary integrity.

  • License: MIT License (Permissive & Open)
  • Checksums: SHA-256 published with every release
  • Auditing: Publicly verifiable repository code

Engineered for Focus

Engineered Beyond Conventional Readers

Semply bridges native desktop horsepower with thoughtful typography, distraction-free ergonomics, and algorithmic reading automation.

Offline MuPDF WebAssembly PDF Reflow

Tired of squinting at tiny two-column PDFs on desktop screens? Semply embeds a compiled MuPDF WASM core inside a background Web Worker. It executes a 2-pass spatial text-flow reconstruction entirely on your local machine, transforming rigid academic and technical PDFs into fluid, resizable text with customized fonts and margins.

Native WebAssembly • Zero Cloud APIs

Dual-Mode Hands-Free Auto-Scroll

Read hands-free with precision. Choose between Fixed Countdown Timer (3 to 600s) or Smart Pace, which dynamically counts visible word density on each page to calculate the ideal reading interval automatically.

Fixed Seconds & Smart Pace WPM

77-Font Curated Typography Library

Includes 12 built-in publisher fonts plus 65 curated Google Fonts spanning Book Serif, Clean Sans, Editorial Slab, and OpenDyslexic accessibility faces. Downloaded once, cached to disk forever.

Offline-First Caching Engine

Dual-Anchor SVG Annotations

Highlights never drift. Semply anchors annotations by both exact text substring and DOM CFI ranges, rendering SVG overlays that survive font size adjustments, margin widening, and window resizes.

Drift-Proof Highlights & Export

Four Contrast-Preserving Themes

Obsidian (#0a0a0a), Clean Daylight, Warm Paper Sepia, and Dusk Evening. Carefully engineered semantic CSS tokens prevent image contrast inversions while synchronizing native OS window backdrops.

Global F9 Instant Cycling

Instant Full-Book Spine Chapter Search

Search multi-hundred-page volumes in milliseconds. Semply iterates across the entire EPUB spine in the background, extracting surrounding context sentences with regex matching and instant one-click jump navigation without blocking your reading thread.

Background Spine Indexing • Zero UI Lag
